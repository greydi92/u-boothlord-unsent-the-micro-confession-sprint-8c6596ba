A program that writes one micro-confession — a `To:` line and the unsent message itself, exactly as it was typed — to `/output/entry.txt`.

Bounty: https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Node 22+, no dependencies, no network.
